# Port Knock

اپ اندروید برای فرستادن ناک‌های پشت سر هم (TCP / UDP / ICMP) به روتر و بررسی باز شدن در.

## استفاده
1. آدرس مقصد (IP یا دامنه) را بنویس.
2. با دکمه `+` ناک اضافه کن و نوع و پورت هر کدام را بزن (مثلاً TCP 666، TCP 777، ICMP).
3. «پورت تست» را بزن (مثلاً 8291 برای Winbox). اگر خالی بماند، نتیجه با پینگ بررسی می‌شود
   (با قانون «Ping after knock» در فایروال هم‌خوان است).
4. «تأخیر» فاصله بین ناک‌هاست؛ باید کمتر از `address-list-timeout` هر مرحله باشد.
5. دکمه پایین را بزن. اگر ارتباط برقرار شود در باز و سبز می‌شود، وگرنه بسته می‌ماند.

## ساخت APK بدون Android Studio
فایل‌ها را در یک مخزن GitHub بریز. تب **Actions** ← **Build APK** ← **Run workflow**.
بعد از اتمام، فایل APK را از بخش **Artifacts** همان اجرا دانلود کن.

## نکته‌ها
- اندروید اجازه ICMP خام نمی‌دهد، پس ناک ICMP با دستور `ping` خود سیستم فرستاده می‌شود.
- ناک TCP/UDP فقط بسته اول را می‌فرستد و جواب نمی‌گیرد؛ خطای اتصال طبیعی است.
- حداقل نسخه اندروید: 8.0
